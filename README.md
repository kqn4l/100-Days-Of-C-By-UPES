# 100 Days of Code — C Programming

This repository documents my journey through the **100 Days of Code in C Programming** challenge assigned as part of the academic curriculum at **UPES (University of Petroleum and Energy Studies)**.

The challenge focuses on building strong programming fundamentals, enhancing logical thinking, and mastering the **C programming language** through consistent daily practice.

---

## 🎯 Objectives

* Build deep understanding of low-level memory, pointers, and data structures in C
* Practice structured algorithmic problem solving every day
* Maintain a clean, documented repository of solutions with sample test cases
* Cultivate discipline and consistency across 100 days

---

## 🔗 Challenge Resources

* **Challenge Portal**: [100 Days of Code — Basic Coding with C](https://maitysoumik.github.io/basic-coding-with-c/)
* **Format**:
  * **Phase 1 (Days 1–50)**: Two problems per day (100 problems total)
  * **Phase 2 (Days 51–100)**: One problem per day (50 problems total)
